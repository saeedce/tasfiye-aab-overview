# Water Treatment Customer Manager

A Qt application for managing customer relationships and service visits in water treatment workflows. The project targets desktop and Android devices and is built with Qt Quick and C++.

## Overview

The app helps users find and maintain customer records, manage primary and secondary phone numbers, and keep a dated history of visits using the Solar Hijri calendar. It also supports creating backups, including an optional self-hosted backup service.

## Highlights

- Desktop and Android application
- Customer search and record management
- Support for two phone numbers per customer
- Visit history with Solar Hijri dates
- Local data storage and backup/restore workflows
- Optional self-hosted backup server

## Project scope

This public repository is an overview only. It does not contain the application source code, customer records, backup files, server credentials, API keys, or private network settings. The implementation is maintained separately.

## Technology

- Qt 6 and Qt Quick
- C++17
- CMake
- Android SDK/NDK for Android builds

This project is intended for customer and service-visit management. Review your local data handling and backup setup before using it with real customer information.
